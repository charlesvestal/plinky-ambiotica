# Charles Vestal

I build instruments that reward letting go of them.

## Ambiotica

A generative-ambient instrument for Plinky 12: a rolling looper, a granular scatter cloud, a
freezing micro-loop, a Dattorro plate and a bank of tuned resonators, with an 8-track x0x drum
machine running dry underneath. Play a few notes and let go.

Designed for the **Chords** faceplate, on a rule the panel keeps everywhere: a pad stays dark
until it has a function that matches its printed label. The silkscreen is the manual, so
PATTERN generates rhythms, MODULO sets every-Nth-time conditions, LENGTH gives each track its
own loop, and RHYTHM holds the shuffle. It runs on any Plinky 12 - on another faceplate you
only lose that correspondence.

The DSP is vendored from [ambiotica-plugin](https://github.com/charlesvestal/ambiotica-plugin)
(MIT), ported to fixed arenas with no heap in the audio path.

Source, issues and build notes: <https://github.com/charlesvestal/plinky-ambiotica>
